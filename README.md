# 📖 Overview



**MediCare Hub** is a modern healthcare platform designed to simplify healthcare management by connecting patients with doctors through an intuitive, secure, and responsive web application.



Patients can browse doctors, schedule appointments, manage bookings, publish health-related articles, and securely authenticate. The application focuses on clean UI, scalable architecture, responsive design, and modern development practices.

# ⚙️ Installation



Clone the repository



```bash

git clone https://github.com/ShamimKhan2006/medicare_hub_client.git

```



Move into the project



```bash

cd medicare_hub_client

```



Install dependencies



```bash

npm install

```



Run development server



```bash

npm run dev

```



Visit



```

http://localhost:3000

```



---



# 🔑 Environment Variables



Create a `.env.local`



```env

NEXT_PUBLIC_API_URL=



NEXT_PUBLIC_BASE_URL=



BETTER_AUTH_SECRET=



BETTER_AUTH_URL=



MONGODB_URI=

```
